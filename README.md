# goit-js-hw-07

## Overview

This repository contains the JavaScript homework project for GoIT course module 07. It includes five interactive tasks that demonstrate DOM manipulation, event handling, and basic JavaScript logic in standalone HTML pages.

## Project Structure

- `index.html` — main entry and navigation page
- `task-1.html` through `task-5.html` — individual practice tasks
- `css/` — styles for common and task-specific pages
- `js/` — JavaScript files for each task

## Tasks

1. `task-1.html` / `js/task-1.js` — first DOM interaction practice
2. `task-2.html` / `js/task-2.js` — form handling and event logic
3. `task-3.html` / `js/task-3.js` — dynamic content updates
4. `task-4.html` / `js/task-4.js` — animation or timing-based interaction
5. `task-5.html` / `js/task-5.js` — final exercise with combined behaviors

## How to Run

1. Open the project folder in VS Code or any code editor.
2. Open one of the HTML files in a browser, or use a local server extension for live preview.
3. Each task page loads its corresponding CSS and JavaScript automatically.

## Notes

- `css/common.css` contains shared styles used across multiple pages.
- Each task has a dedicated stylesheet in `css/` and a corresponding script in `js/`.
- The project is designed for practice and learning rather than production use.
